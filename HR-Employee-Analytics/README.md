# HR Employee Analytics Dashboard

## Project Overview

This project analyzes employee data to identify key HR trends, employee attrition patterns, and salary insights.

The project combines Python, SQL, Excel, and Power BI to perform data analysis and create an interactive HR analytics dashboard.

## Objectives

- Analyze employee attrition
- Identify departments with higher employee turnover
- Analyze attrition based on age groups
- Analyze the relationship between overtime and attrition
- Compare average monthly income across departments
- Create an interactive Power BI dashboard

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL
- SQLite
- Microsoft Excel
- Power BI

The dashboard contains:

- Total Employees
- Employees Left
- Attrition Rate

- Employee Attrition by Department
- Employee Attrition by Age Group
- Employee Attrition by Overtime
- Average Monthly Income by Department

## Key Findings

- Total employees: 2,000
- Employees who left: 520
- Overall attrition rate: 26%
- Average monthly income: approximately 9,395
- Research & Development has the highest average monthly income among the three departments.
- Overtime is associated with a noticeable difference in employee attrition.
